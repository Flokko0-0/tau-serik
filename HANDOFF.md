## Что уже сделано

Веб-приложение безопасности для гор Алматы. Подробный список функций, архитектура и честный список того, что имитируется, - в `README.md`. Коротко:

- регистрация по ИИН (настоящая проверка контрольной цифры), eGov (имитация), согласие на обработку данных, медкарта, близкие;
- 7 настоящих маршрутов из OpenStreetMap, профиль высот, прогноз Open-Meteo на высоте вершины, оценка риска, список вещей, свой маршрут по двум точкам;
- режим «В горах»: падение, крик, кодовое слово → «Вы в порядке?» → SOS близким с координатами и медкартой; контрольное время, время разворота, предупреждения о грозе, уходе с тропы и темноте;
- экран близкого: маршрут, точка, SOS с сиреной, вопрос «Всё в порядке?», push через приложение ntfy;
- «Компания»: анкета, объявления, зашифрованные заявки и чат, обмен контактами по согласию;
- ИИ-помощник на Gemini, без интернета - встроенная сводка;
- офлайн: карта, трек, 17 памяток первой помощи, очередь сообщений.

## Как запустить у себя

Нужен Node.js 20 или новее (и Python 3.10+, только если будете пересобирать данные или ролик).

```bash
git clone https://github.com/Flokko0-0/tau-serik.git
cd tau-serik
npm start        # открыть http://localhost:5180
npm test         # 25 тестов, все должны пройти
```

Локально ключа Gemini нет, поэтому помощник отвечает встроенной сводкой. Чтобы включить ИИ у себя: Профиль → ИИ-помощник → вставить ключ (он сохранится только в этом браузере).

Датчики, микрофон и GPS на телефоне работают только по HTTPS, то есть на опубликованном сайте, а не на localhost.

## Как опубликовать изменения

1. Попросите владельца репозитория (Flokko0-0) добавить вас: Settings → Collaborators → Add people → ваш ник на GitHub.
2. Изменили файлы → `git add -A` → `git commit -m "что изменили"` → `git push`.
3. Через минуту сайт обновится сам: GitHub → вкладка Actions → «Публикация на GitHub Pages» должна стать зелёной.

Ключ Gemini хранится в секретах репозитория (Settings → Secrets and variables → Actions → `GEMINI_KEY`) и подставляется при публикации. Не вписывайте ключ в код: GitHub заблокирует такой коммит. Чтобы сменить ключ, обновите секрет и запустите публикацию заново: Actions → «Публикация на GitHub Pages» → Run workflow.

## Демо-пульт

На ноутбуке слева от приложения, на телефоне внизу профиля. Кнопки имитируют падение, крик, кодовое слово, шаги по тропе, отключение сети и просроченное время. Демо-профили «Айым, 22 года» и «Дана, 16 лет» уже заполнены: медкарта, близкие, анкета.
